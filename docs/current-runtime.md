本次日期维护按冻结证据检查 63,802 项、更新 62,813 项 chronologicalAt；原始 SHA、对象、创建／添加时间不变。排序优先可靠摄影日期，无此信息时使用已记录的来源日期，最后才回退添加时间；不把来源文件日期冒充 EXIF。首页、分段和全库日期索引共用 chronologicalAt。
