## 本次修改

- 在线状态由大块居中面板改为紧凑连接横幅，减少与顶部“返回图库”重复。
- 存储区改为一张主卡：左侧当前账号占用、占比和文件数；右侧全部缓存、使用率胶囊、当前账号／其他或旧缓存分段条、磁盘剩余。
- “长期使用”显示持久统计：本机命中率、累计免下载、缓存文件与平均大小；命中率附细进度条，零数据时显示“还没有长期数据”而不是 0%。
- “本次连接”改为分段条与计数标签：本地直读、联网确认、联网下载、同批等待、读取失败；突出本次完全免网比例和本次免下载字节，并说明重启归零。
- 补上缓存目录显示；容量上限、打开缓存文件夹和清空当前账号缓存收进一张设置卡，危险操作单独用暗红行。
- 增加“这些数字是什么？”折叠说明，区分长期统计、本次连接、免下载流量和旧地址缓存。
- 全部文案补中英文；空状态、未登录和零读取均有明确显示。
