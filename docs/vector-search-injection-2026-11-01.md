# 双模式 2B 内容搜索恢复

2026-11-01。用户反馈照片与素材搜索均只显示“没有匹配”，网页和桌面为验收范围。

## 原因与修复

`EagleService`将`EagleImageSearchService | undefined`标记为`@Optional()`，TypeScript运行时参数元数据为`Object`。Nest无法按该元数据注入已登记的搜索provider，却因为可选而继续启动；主搜索静默进入名称／人工标签路径，响应也没有`imageSearch`状态。模型、向量数据和服务健康检查正常，不能据此证明搜索链路已装配。

改为显式`@Inject(EagleImageSearchService)`，移除可选注入。两种模式仍使用原能力登记、原搜索实现和各自不可变模式；缺失依赖时启动失败。搜索模型、阈值、精确排序、完整分页及权限规则沿用原契约。

新增真实Nest装配测试：两种模式均验证查询进入向量服务并返回语义状态，缺失provider时均拒绝启动。修复前四项全部失败，修复后通过。成品HTTP回归检查两模式即使模型空间不可用也明确返回`UNAVAILABLE`，不会静默跳过整个能力。
