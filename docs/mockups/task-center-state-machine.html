设计说明
  • 状态只有五个：排队、执行中、已完成、失败，外加“受阻”作为排队的一个展示态。
  • 阻塞不是状态，是守卫没通过。所以“为什么不动”放在守卫里，不塞进任务状态词。
  • 状态图上的数量就是各类别当前之和，和下面的类别表能对上，不做二次推断。
  • 迁移记录只追加：每次状态变化留一条，能看到 QUEUED → RUNNING 是谁在什么时候触发的。
  • 繁忙退避记成 RUNNING → QUEUED，不计失败；失败才是终止态，只能重试回到排队。
  • 状态码用等宽字，数量用等宽数字，扫描时对齐；中文名仍然优先。
  • 窄屏下状态图改为纵向流转，守卫与类别行折行，不横向滚动。
