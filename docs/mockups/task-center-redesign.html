设计说明
  • 一个任务只显示一个当前状态，原因紧跟其下，不再用聚合数反推状态。
  • 每行只留一个主数字“剩余”；运行与失败是次要指标，完成量单独成段。
  • 按可操作性分区：需要你 → 正在处理 → 等待条件 → 已暂停 → 最近完成。
  • 状态用日常词（运行中 / 等待时段 / 已暂停），不用“计算ing”这类拼接词。
  • 运算位置、速率、预计时间放在次级层，不占标题。
  • 容量繁忙与离线在文案上分开：繁忙只说“自动重试”，不冒充离线。
  • 行内只保留展开按钮，暂停与重试放进展开区，减少误触和视觉噪音。
  • 窄屏下数字换到第二行，不横向滚动；展开区与卡片单列排布。
  • 查看“模型繁忙”版式：繁忙与离线用不同措辞和颜色，不互相冒充。
