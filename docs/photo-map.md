# 照片夜间地图

2026-10-19：移除浏览器直接请求 OpenStreetMap 海外瓦片的实现。默认地图改为应用自身静态资源提供的本地概览，以确定运行时不依赖国内访问海外地图的网络条件。

## 显示与使用

- 海洋／背景使用网站 `--eagle-bg`，陆地使用 `--eagle-panel-raised`，照片标记及交互控件使用 `--eagle-accent`，目前为炭黑／琥珀黄。城市标签、缩放按钮和弹窗同样适配深色。
- 本地数据提供陆地轮廓与城市名称，包括中文城市名；城市标签按优先级避让，每次最多 60 个。底图仅在进入地图时按需加载，不进入主 JS 包。
- 默认取照片范围，支持拖拽、缩放、点击照片点打开预览，以及「显示全部照片位置」复位。切换选择或打开详情不会重新创建地图；容器尺寸变化会刷新画布。
- 明确显示「离线概览 · 不含街道级细节」。该数据集不是街道导航地图，也不能据此宣称具有高精度道路、实时交通或国内完整行政边界。
- 地图脚本、样式和数据均从本应用加载，无外部瓦片、字体、定位、坐标转换或地理编码请求，无需第三方地图 Key。应用服务器本身仍须可访问；资源首次加载需要能连接应用服务器，不能据此声称整个应用具备断网安装／缓存能力。
- 资源加载失败时保留照片位置交互并提示重试，不偷偷切回海外瓦片。照片 EXIF 坐标保持 WGS84；不套用高德／百度底图的偏移坐标。

## 数据来源与更新

Natural Earth 官方说明其矢量数据属于公有领域，允许修改与再分发：<https://www.naturalearthdata.com/about/terms-of-use/>。

提交的数据是 1:50m land 与 1:10m populated places 的精简版本，去除无关属性，保留地图几何、城市名称／坐标／人口和标签缩放级别。固定上游修订、下载地址、SHA-256 与处理过程记录在 `apps/web/src/components/photos/basemap/sources.json`，许可也记录于根目录第三方声明。

维护者可运行 `node scripts/maps/build-basemap.mjs` 从固定修订重新生成；它是显式维护命令，正常 build 和运行地图都不会访问该上游仓库。提交的两个数据文件未压缩合计约 2.1 MB。

街道级地图如后续需要，应独立接入天地图、高德等正式授权国内服务，并处理相应坐标系；本轮不添加未授权瓦片、不代申请或嵌入他人 Key，也不假装已经完成国内运营商连通性实测。本地资源方案通过移除外部地图请求消除翻墙依赖。

## 本轮验证

根目录 lint、typecheck、unit test、build、format 和 OSS 检查通过；最终 Web 回归为 49 个文件、271 项测试通过。新增测试覆盖仅请求同源打包数据、不创建外部瓦片层、照片名作为纯文本、失败提示与重试、回调更新不重建地图、城市标签可见性与数量限制。浏览器实看中文城市标签、黑黄配色、缩放、照片范围复位与深色弹窗，截图位于 `.omx/artifacts/night-map.png` 及 `night-map-popup.png`；独立测试页面仍在原本地地址，未部署现用实例。
