## 显示与使用

- 海洋／背景使用网站 `--eagle-bg`，陆地使用 `--eagle-panel-raised`，照片标记及交互控件使用 `--eagle-accent`，目前为炭黑／琥珀黄。城市标签、缩放按钮和弹窗同样适配深色。
- 本地数据提供陆地轮廓与城市名称，包括中文城市名；城市标签按优先级避让，每次最多 60 个。底图仅在进入地图时按需加载，不进入主 JS 包。
- 默认取全库有效位置范围，支持拖拽、缩放、点击位置组浏览照片，以及「显示全部照片位置」复位。切换选择或打开详情不会重新创建地图；容器尺寸变化会刷新画布。
- 明确显示「离线概览 · 不含街道级细节」。该数据集不是街道导航地图，也不能据此宣称具有高精度道路、实时交通或国内完整行政边界。
- 地图脚本、样式和数据均从本应用加载，无外部瓦片、字体、定位、坐标转换或地理编码请求，无需第三方地图 Key。应用服务器本身仍须可访问；资源首次加载需要能连接应用服务器，不能据此声称整个应用具备断网安装／缓存能力。
- 资源加载失败时保留照片位置交互并提示重试，不偷偷切回海外瓦片。照片 EXIF 坐标保持 WGS84；不套用高德／百度底图的偏移坐标。

## 数据来源与更新

Natural Earth 官方说明其矢量数据属于公有领域，允许修改与再分发：<https://www.naturalearthdata.com/about/terms-of-use/>。

提交的数据是 1:50m land 与 1:10m populated places 的精简版本，去除无关属性，保留地图几何、城市名称／坐标／人口和标签缩放级别。固定上游修订、下载地址、SHA-256 与处理过程记录在 `apps/web/src/components/photos/basemap/sources.json`，许可也记录于根目录第三方声明。

维护者可运行 `node scripts/maps/build-basemap.mjs` 从固定修订重新生成；它是显式维护命令，正常 build 和运行地图都不会访问该上游仓库。提交的两个数据文件未压缩合计约 2.1 MB。

街道级地图如后续需要，应独立接入天地图、高德等正式授权国内服务，并处理相应坐标系；本轮不添加未授权瓦片、不代申请或嵌入他人 Key，也不假装已经完成国内运营商连通性实测。本地资源方案通过移除外部地图请求消除翻墙依赖。

## 2026-10-23 全库聚合与位置选片

这次修正首页分页造成的地图缺片：地图不再读取首页已经加载的资源，也不再提供「载入更多照片」。服务端聚合当前账号 PHOTO 库中所有已记录的有效位置，不依赖首页页数和封面是否已生成。GPS 缺失且没有已接受补充位置的资源仍不出点；原片中尚未提取的位置，需要现有元数据任务完成后才会出现在统计中。

### 聚合语义

- 初次查询覆盖全世界，返回全库有位置照片数与范围，前端自适应后按当前视口查询。计数包含单张资源，不以折叠后的照片组封面数量代替照片数。
- 使用随缩放细分的 Web Mercator 网格：缩小时是区域／城市尺度，放大后细分附近位置组，查询最大缩放 16，最细网格约为赤道附近 38 米（2026-10-24 从 level 14 细化至 20）；实际视口仍受 1024 个理论网格预算约束。不是行政区边界或城市识别，不能承诺每座城市恰好一个点；相邻城市在较远视角可能合并，城市在近处可分多个组。
- 标记放在网格代表点，属于模糊分组位置，不冒充每张照片的精确拍摄位置。2026-10-24 起采用真实照片缩略图与数量角标，标记落在本组照片最密集区域的代表坐标；网格仅用于聚合身份，不再将可见标记固定在网格中心。
- 一次最多覆盖 1,024 个网格位置。对不合理的「高缩放＋全世界」请求降低聚合精度，保持完整统计，不用 LIMIT 截断坐标。跨日期变更线的视口可查询两侧。
- 计数覆盖完整网格，选点成员使用同一投影与网格规则，避免视口边缘出现「圈内 20 张、打开 30 张」的差异。地图平移／缩放不改变已经打开的位置组，重新选点才改变照片范围。

### 查询与复用边界

`PhotoMapService` 是摄影专属聚合适配器。原始 GPS 仅使用当前媒体版本的元数据，缺失时回退当前版本的已接受城市级补充位置；不改写 EXIF 或写回推断坐标。所有查询在服务端限制 owner、PHOTO、未删除和私密可见性，来源关系同样匹配 owner／模式／版本。

接口：

- `GET /api/photos/photography/map`：`west/east/south/north/zoom`；返回全库总数、全库范围及当前网格计数。
- `GET /api/photos/photography/map/:cell/photos`：选点后按 chronologicalAt 和 ID 降序取成员，每页最多 60 张。游标绑定账号、PHOTO、私密状态和网格，不能跨作用域继续翻页。

点内分页是照片面板的浏览方式，不影响地图完整性。桌面显示右侧照片面板，窄屏改为上下排列；复用 `EagleAssetThumbnail`、共用有界加载服务和原查看器。打开当前页任意照片时，查看器使用该页的上下文，照片不在首页已加载列表中也能显示详情、翻片和视频。上下文绑定账号／模式／私密作用域，变化时清理。

地图明确展示全库位置，因此不再展示仅影响首页列表的搜索／快捷筛选控件，避免出现筛选了列表却误以为地图也已筛选的情况。本轮没有添加另一套通用筛选器。

- 本机归档位于忽略目录 `.local/maps/data/basemap.pmtiles`，来源、范围、SHA-256 记录在同目录 `sources.json`。约 6.7 GB，不进入源码或应用镜像。本机可用空间不足以容纳约 139 GB 的全世界详细数据，因此采用区域提取。

- 渲染层封装在 `self-hosted-basemap.ts`，复用现有 Leaflet 与 protomaps-leaflet 5.1；Canvas 字体使用系统字体，无远程字体、sprite 或地图 SDK 请求。该 Leaflet 适配库处于维护模式，单独封装使未来更换渲染器不影响照片查询、标记或查看器。
- 开发工作台直接读取本机地图目录；生产网页 Nginx 已预留只读文件路径 `/usr/share/nginx/maps/basemap.pmtiles`，部署时需单独挂载地图目录。本轮未挂载或部署群晖。无归档时保留原有 Natural Earth 概览，并显示“详细地图尚未安装”，不把它冒充高精度地图。

### 生成与更新

- `EaglePhotoMapState` 按 owner／PHOTO 合并待更新状态。照片和位置写入的数据库触发器仅更新版本及时间，不提取位置、不聚合、不逐张启动地图任务。
- 首次构建不等待静默期；已有地图的普通增量连续一分钟没有相关变更后可整理，持续导入最多合并十分钟再取一次固定版本。worker 在媒体任务间隙，每十五秒最多执行一个有界步骤；交互任务优先，基础地图维护不受可选图片分析的夜间时段控制，仍遵守进程后台处理总开关。
- 首步只提取一次有效位置，冻结资源版本与坐标。后续每步最多计算四个空间级别，分别保存公开／含私密的总量、范围与实际拍摄代表点。构建不是前端网格排版，代表点来自最密集细分区域的一张真实照片，不用平均坐标或格子中心冒充拍摄地点。
- 已提交层级可渐进读取，无旧图时先显示粗层级，有有效完整旧图时保留其精度直到新图具备所需层级；完整后原子切换活动快照，普通新增期间注明后台更新。构建中又新增照片会合并到下一批，不在每次上传后重新计算。
- 隐私、删除、替换或已有位置变化立即让旧可见性版本失效，等待新版本，避免继续暴露旧位置或数量。初次构建／失效时显示“后台整理”，不误报没有 GPS。
- 租约与发布校验防止多 worker 重复发布；失败回滚当前步骤，指数退避后从固定位置集继续；新增事实仍更新版本和敏感可见性，但不清除失败计数或更改既有重试截止，成功步骤才重置失败预算。保留当前和前一完成快照，成员游标绑定快照、主体和私密权限；更旧位置返回 404，提示重选。

### 显示

所有返回位置使用一个 Canvas 小点图层，位置不为避让缩略图而移动。密集像素允许自然重叠；空间查询按视口选择已生成的合适级别，预算增至 16384 个理论格，不按照片数量截断足迹。低缩放的小点代表附近位置组，放大细分，不能把每个点理解成单张照片或行政区。

照片预览缩至 40px：缩放 ≤3 时至少 1000 张、≤5 时至少 100 张、≤8 时至少 10 张、≤11 时至少 3 张，其后至少 1 张。最多预取 512 个按数量优先的封面；避让只决定是否显示照片预览，不删除足迹、不合并成员、不把照片挪到外围。高数量位置优先显示；预览重叠时小点仍可点击打开照片面板，另有手动放大按钮。
