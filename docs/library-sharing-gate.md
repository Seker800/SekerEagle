# 图库边界与能力归属门禁

现行契约见[架构北极星](architecture.md#north-star)。本文件描述可执行的门禁范围；历史变更保存在[归档](history/library-sharing-gate-through-2026-11-01.md)。上线状态只读[现用运行](current-runtime.md)。

## 共用范围与允许差异

素材／照片共用上传、资源读写、发送、回收、筛选、搜索、缩略图、选择、查看器及操作回执。人物、地图、摄影统计和整理建议属于摄影扩展，通过既有资源及事务原语集成。

允许按能力提取目录、hook、应用服务或provider。新抽象必须明确持久状态归属、依赖方向和唯一写入口；禁止的是复制事实、权限或写入规则，而不是类或文件增加。共享provider按`library-capabilities.ts`的能力登记装配，MATERIAL专属maintenance在注册时声明模式，PHOTO模块不再复制清单后临时排除。

模式token是必需依赖；漏装配必须启动失败。独立执行器显式固定每个mode，不借构造器默认值替代装配。共享控制器继承保持实现一致，摄影扩展不能覆盖原写路径。

## 静态门禁

`npm run architecture:check`与反例测试覆盖：

- 两模式使用唯一共享工作区、卡片、缩略图、筛选、布局及查看器。
- 共享渲染代码的import及明确lazy边界，不接受仅提到原模块的伪装装配。
- 摄影控制器空继承；共享provider身份、能力登记、模式绑定及依赖唯一性。
- Prisma模型与能力／非共享领域归属双向对应；新增未登记表、跨领域重复归属或失效表名均拒绝。
- 浏览器和纯规则包的依赖方向，明确阻止Node、持久化、S3与服务端渲染入口；服务端适配包允许自己的IO。
- 共享层不得反向依赖摄影实现；装配点是显式边界，不能把通用卡片和布局的模式分支塞入其中。
- 处理器版本和任务种类使用共同登记；规则包不能反向依赖应用。

静态检查是已登记边界的证据，不证明任意程序等价。不能通过禁止所有原始SQL、所有PHOTO字面量或所有新增provider来替代领域判断。扩展允许范围时同时补反例：未登记服务、第二套写路径、非法依赖不能因为文件换名而通过。

## 运行时与数据库契约

`apps/api/src/photos/library-sharing-contract.test.ts`验证两模块共用provider身份及路由实现。模式缺失装配反例要求失败。认证／跨owner404、私密、媒体版本、租约、回收、发送及并发发布由原API和隔离数据库测试验证；不把这些测试换成静态字符串匹配。

时段规则的JS／SQL等价测试覆盖跨午夜、相等端点、边界时刻和非法设置。Prisma枚举与纯规则登记对照，防新增任务只改一端。OpenAPI生成产物检查进入CI，客户端优先复用共用协议类型，按实际响应逐步补齐schema，不凭一次生成声称所有端点已有类型保障。

核心响应契约测试要求两个模式的列表、详情、回收站及操作回执均引用具名schema，并核对必需字段、空值与存储／owner字段边界。网页使用生成的资源与回执类型，领域操作DTO对照`library-core`协议；生成物必须与实际控制器同步。选择／预览／元数据草稿回归覆盖跨作用域清理、互斥预览、分页增量保留选择及过期保存回执，人物合并覆盖普通目录和筛选选项的私密目标移除。

## 本地与 CI

运行`npm run architecture:check`、`npm run test:architecture`及完整`npm run ci:check`。API成品镜像发布仍须独立启动验收，历史升级和完整恢复仍须真实隔离数据库，门禁通过不自动授予生产发布或数据操作权限。

## 基础颜色筛选共用约束

素材与照片复用 `library-core/color-search`、`color-palette` 和唯一 SQL 适配器；没有新增模式专属 provider 或提取器。`AssetSearchWhere.colorMatch` 必须通过 `findSearchAssets`、`countSearchAssets` 或颜色分页适配器执行；Prisma 仅用于保留权限条件的当页投影。`scripts/testing/color-search.mjs` 以真实隔离数据库核验数值、布尔组合、权限、媒体版本、前后分页及六万项代价。

## 架构效率优化的执行宿主约束

上传恢复与维护保持原能力和持久事实归属，共享provider在HTTP模块中只提供领域入口；独立operations显式装配后台宿主并负责启动、续行与排空。共享装配不等于允许API模块生命周期执行后台业务。门禁及反例须覆盖自动启动业务定时器、未登记的后台宿主和第二套恢复状态；保留独立执行器与worker正常租约心跳，不粗暴禁止setInterval。

本轮穷尽操作登记和语句分批门禁只约束已列明的执行路径，不全仓禁止500／512或所有定时器。反例验证漏登记、陌生直接准入、裸批次回归及API后台自动启动。宿主迁移不删除能力专属扩展：PHOTO上传恢复继续装配原摄影修订observer，MATERIAL不注入；实际替换恢复测试证明媒体修订和摄影事实失效仍生效。

## 数据库批次门禁的边界

五个已登记持久化路径禁止500／512裸目标、直接本地别名、旧OPERATION_DB_BATCH_SIZE导入别名及简单传递别名。它防止旧写法回归，不证明未知size、跨函数数据流或未登记文件的预算。命名预算的字段宽度、固定绑定、Prisma隐含参数仍须真实数据库边界与审查共同证明；新增路径要决定是否扩展登记并补反例。详细范围和验收契约见[后续修复](architecture-efficiency-review-followup-2026-11-01.md)。
