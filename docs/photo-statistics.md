# 照片统计

2026-10-24 本机实现和验收，尚未部署群晖应用。

## 入口与口径

照片模式左侧「智能整理」下面的「照片统计」提供拍摄量折线、相机使用量和镜头使用量两张柱状图。默认全部时间、按月、按相机分线；可切换年／月／日和镜头曲线。相机、镜头可分别多选，两个条件取交集；日期应用后，三张图同步更新。顶部提供全部时间、最近一年（含当天的最近 365 天）和自定义日期；设备筛选可搜索完整型号，展开区域参与正常文档布局，不遮挡或裁切内容。设备使用量按照片数量降序展示为横向排名条，完整显示型号、数量和占比；所有行在页面正常流中展开，不截断名称、不使用横向或内部纵向滚动。点击设备行可直接筛选，再次点击取消，当前条件显示为可移除标签。

统计当前主体的 PHOTO 图片资源，排除视频、回收站和当前无权查看的私密资源。每条图片记录计一张，照片组折叠不减少统计数量。仅使用当前媒体版本的摄影元数据。型号去除两端空白后精确分组，不猜测同型号是否为同一物理机身，不合并名称近似的设备。

使用 EXIF 本地拍摄日期；缺少本地日期但有拍摄时间时按 UTC 日期统计。不使用导入时间替代拍摄日期，未知日期单独计数，并在限制日期范围时排除。无相机／镜头信息归入对应未知分组；过期元数据不能继续作为当前设备事实。

横轴保持真实日历间隔，缺失时间段补零。折线采用低饱和灰蓝色与线型区分设备，支持图例隐藏／恢复、悬停聚焦、指针浮层和方向键查看时间，不再提供常驻滑块。图形按容器宽度测量、固定 216px 高度，避免随窗口变宽占满屏幕。最多 732 个时间段，超出提示缩小范围或切换月／年；超过 23 个设备时，剩余曲线明确合并为「其他设备（合并）」，两张使用量图仍完整展示全部设备，不丢失计数。

## 实现边界

PhotoStatisticsService 是摄影专属只读聚合，不替换共用图库服务。一次数据库查询为三图提供同一快照，SQL 聚合全库而不是浏览器已加载列表。PhotoStatisticsController 复用浏览器认证和主体私密权限；DTO 不接受 owner、模式或私密覆盖参数。型号、日期和粒度参数均验证，查询使用参数绑定。

界面装配在共享工作区的摄影扩展位置，图表和 API 客户端在独立文件维护。统计设备条件仅用于分析视图，不创建第二套图库筛选规则、上传器、缩略图或媒体实现。具名 provider 和拒绝替换共用服务的反例同步纳入架构门禁。

## 本地验收证据

- 后端统计模块单元覆盖率：95.31% 行、88.64% 分支、100% 函数；覆盖日期校验、空结果、粒度、范围、参数绑定和认证主体。
- 页面组件覆盖率：97.84% 行、87% 分支、96.51% 函数，13 项交互测试通过。覆盖三图、月份补零、设备交集、切换曲线、日期应用和清除、失败重试、未知字段、设备重色和时间标签密度。
- `scripts/testing/photo-statistics-integration.mjs` 新建临时 PostgreSQL，执行安全检查和全部迁移，验证真实聚合、超过普通分页数量的计数、owner／PHOTO／私密／版本边界、本地跨月日期、未知日期、过滤及设备曲线上限，结束清理临时容器。
- 经用户授权，在现用群晖 API 容器执行安全目标检查，通过只读事务抽取最多 32 项的冻结样本信息，再只读获取托管原片，检查大小与 SHA256。实际复制 27 张 JPEG；原始数据库样本覆盖 8 个相机型号和 15 个镜头分组，不代表全库分布或最终 EXIF 重新提取后的名称数量。
- 样本只保存在 Git 忽略的本机私有目录，经过本地认证上传和现有 worker 重新处理。测试工作台另有 4 张合成照片，因此默认照片统计为 31 张；合成条件与真实照片不混称。未复制群晖账号、认证或完整数据库，未修改群晖图库、处理任务或部署。
- 工作台 HTTP 验证三图计数一致、设备筛选、未登录 401、身份／私密参数注入与坏日期 400、素材对应路径 404。浏览器验证侧栏位置、真实数据图表和交互。完整 `npm run ci:check`（架构、lint、typecheck、全量单元测试、build、格式与开源检查）通过；API 查询契约已重新生成。

运行 `npm run test:photo-statistics` 可重放隔离数据库验证。真实样本通过 `PHOTO_WORKBENCH_STATISTICS_SAMPLES` 显式指定私有清单后，由既有 `photo-workbench.mjs --serve` 装配；不会默认连接群晖。工作台只监听 loopback；在样本模式使用 127.0.0.1，避免与其他 localhost 端口的登录 Cookie 冲突，测试登录入口每次创建新会话，不重放已轮换的刷新凭据。EXIF 提取使用已有本地 ExifTool。

## 2026-10-24 密度与交互修订

按用户反馈压缩工具栏、概要和图表留白，移除彩色设备柱、常驻时间滑块和横向滚动。数量／占比对齐显示，曲线用灰蓝色与线型区分。切换筛选时保留同一 owner／私密作用域的上一张快照并明确标示更新，减轻跳动；身份或私密权限变化不复用旧快照。仅修改摄影统计呈现，不改聚合口径、API、数据库或群晖服务；复用现有本机测试工作台和照片样本。

本轮浏览器测量：趋势图实际高度 216px，26 行设备排名完整装配，统计区域无横向溢出、无可见滑块；直接选择相机后为 2 张，叠加对应镜头后为 1 张，并在顶部显示两个可移除条件。统计组件新增容器尺寸、指针／键盘与身份变化不复用快照的回归验证。
