# 语义智能文件夹

智能文件夹现在可以保存一段画面描述，例如「海边日落」，与现有评分、标签、相机、日期等规则同时使用。它不移动文件、不写入分类标签，同一图片可以出现在多个智能文件夹中。素材与照片共用实现，数据按账号与模式隔离。

## 使用与状态

在新建或修改智能文件夹中填写可选「画面内容」，选择严格、适中或宽泛。预览是显式操作：从最相关的最多 100 个语义候选中应用普通条件，展示最多 12 张，不声明完整数量。模型离线时仍可保存；后台会重试。

保存后后台分批构建，打开文件夹只分页读取持久化命中关系。默认沿用模式日期排序，可切换相关度排序。新图片在向量发布事务中自动匹配；未生成向量的图片在以后处理完成时补入。普通规则实时求值，包括评分修改和相对日期，无须重新生成向量。

首次生成前结果为空；更新描述或范围时保留上一版结果，成功后原子切换。失败采用有上限的延后重试，连续五次失败后可点击「重新生成匹配结果」。重新保存相同意图不会丢失已有向量；失败状态重新保存会重建。清空画面描述回到原有规则语义，删除相应快照及命中关系。

严格／适中／宽泛目前分别使用余弦相似度 0.35／0.30／0.25，属于可通过预览评估的检索策略，不是正确率或识别置信度。文件夹收录所有超过阈值的图片，不截取搜索前若干张。未来如调整此策略，应重建受影响快照。

## 处理与隔离

- 查询向量和匹配结果保存在 PostgreSQL，重启 API、worker 或 Mac 不丢失。已有文件夹浏览不调用 Mac；新的描述需要 2B 生成一次查询向量。
- worker 每次最多读取 500 个当前版本图片向量并保存游标。独立有界调度遵守后台总开关及 `GENERATE_EMBEDDING` 白名单，不依赖 8B 标签构建开关。
- 构建租约为 12 分钟，覆盖最多 10 分钟模型超时与数据库发布预算。租约令牌防止失去所有权的旧任务发布；未完成任务在租约过期后续算。
- 新向量发布时增量匹配已激活或正在构建的同空间快照，补齐初始游标之后到达的图片。匹配写入幂等，构建、修改和发布使用一致的快照锁顺序。
- 模型空间必须经现有兼容检查显式切换，不能原地更改维度或模型修订。新空间自动排队重建；旧空间已索引的当前照片尚缺新向量时保留旧快照，避免提前切换为空结果。
- 命中关系使用 owner／模式复合外键。读取实时应用账号、模式、私密及回收状态；状态不暴露含私密资源的扫描计数。预览再次校验候选媒体版本。
- 替换原文件时由数据库触发器删除旧媒体版本命中，插入匹配时锁定并校验当前媒体版本。旧空间快照可以继续浏览，但不能使旧像素匹配新原片。
- 相对日期、私密状态和普通筛选不会被冻结到快照；资源回收时隐藏，恢复时按当前规则重新可见。硬删除及删除文件夹通过外键清理关系。

## 发布与验证

新增 migration `20261023150000_semantic_smart_folders`。发布时先备份并执行既有安全目标检查，再应用迁移，随后更新 API、worker、web；本功能的本地验收不授权更新现用部署。不要重建旧 Mac 图库，也不需要开启 8B 或人脸任务。

```sh
npm run architecture:check
npm run lint
npm run typecheck
npm test
npm run build
npm run test:smart-folders
```

`test:smart-folders` 创建使用 tmpfs、loopback 端口及 `sekereagle_test` 数据库的独立 pgvector 容器，迁移前运行安全检查，结束清理。测试覆盖超过单批／单页的完整结果、游标中途新增、缓存浏览不调用模型、实时规则、账号／模式／私密边界、替换、重试、租约、空间变更与级联清理，并为新增检索与持久化模块启用 80% 覆盖率门槛。测试只使用合成资源，不依赖生产照片或真实模型。
