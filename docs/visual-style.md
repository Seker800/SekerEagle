# SekerEagle 网页视觉风格

2026-10-24，经用户确认，将照片统计的紧凑、低饱和风格推广到整个网页。本文是后续页面和组件的视觉依据，设计变量以 `apps/web/src/design-tokens.css` 为唯一来源。素材与照片共用视觉实现，业务边界继续遵守 architecture.md；不改变安卓原生界面的独立设计方向。

## 设计原则

界面应像专业摄影工具：深石墨底色、克制的灰蓝强调、清楚的数据层级。把视觉空间留给照片、作品和需要比较的信息，少用装饰。通过字号、对齐、边界和空间组织内容，而不是为每项内容分配不同颜色。

- 信息密度：工具集中在顶部，摘要横向排列，明细使用对齐的行；功能相关的项目靠近，独立区块之间留足间隔。
- 表面层级：页面、侧栏／面板、浮层三层明暗即可；常规内容用细分隔线，不反复嵌套卡片。
- 控件克制：小圆角、细边框、稳定位置；选中状态使用低饱和底色配文字／图标变化。
- 内容完整：长设备名和说明可以换行；省略的名称必须能在详情中读取。避免用多个局部滚动框隐藏主要内容。
- 操作可预期：保留既有导航与业务流程；筛选清晰显示当前值，浮层仅展示当前操作所需信息。

## 色彩

| 用途           | 变量               | 值        |
| -------------- | ------------------ | --------- |
| 页面背景       | `--ui-bg`          | `#111214` |
| 侧栏、面板     | `--ui-panel`       | `#17181b` |
| 浮层、抬高表面 | `--ui-raised`      | `#202226` |
| 输入底色       | `--ui-input`       | `#101114` |
| 中性选中表面   | `--ui-selected`    | `#2a2d31` |
| 主文字         | `--ui-text`        | `#f0f1f3` |
| 次级文字       | `--ui-secondary`   | `#bec4cb` |
| 辅助文字       | `--ui-muted`       | `#969ca5` |
| 灰蓝强调       | `--ui-accent`      | `#94a5b4` |
| 强调文字       | `--ui-accent-text` | `#c6d2dc` |
| 细边界         | `--ui-line`        | 白色 8%   |
| 弱分隔         | `--ui-line-subtle` | 白色 4%   |

强调色用于焦点、选中项、主要动作和图表，不铺满整页。不把金色、亮蓝色、渐变或玻璃高光作为另一套主题。普通表面为不透明底色；阴影用于浮层边界，不用于常规排名或数据行。

错误、危险操作、在线状态与警告保留语义色。用户标签色、图片提取色板、摄影编辑器的真实色彩调节、照片原始颜色属于内容，不受灰蓝主题替换。查看器的黑底、遮罩与画布棋盘也保留其功能。

## 字体与数字

沿用系统无衬线字体，不增加字体下载。工作区正文和控件以 12px 为基准，分区标题 13px，页面标题 17px，主要数据 24–30px。说明和辅助刻度可用 10–11px，但不能用低对比小字承载关键操作或唯一状态。

数字使用等宽数字特性 `tabular-nums`，数量和百分比右对齐；名称左对齐。正文行高约 1.5，标题使用 500–600 字重，避免整页加粗。登录介绍允许更大标题，其表单继续遵循共用控件样式。

## 尺度与排版

- 间距基于 4px：4 / 8 / 12 / 16 / 24；页面横向内边距通常为 24px，小屏 10–16px。
- 桌面控件通常高 28–32px；表单输入 36px，登录输入 44px。小屏常用触摸按钮保持至少 42px，不通过压缩触摸目标获得密度。
- 控件圆角 5px，内容面板圆角 6px；圆形人物头像、状态点和具有明确交互含义的胶囊可保留自身形状。
- 工具栏允许合理换行；两栏内容使用 `minmax(0, 1fr)`，小屏转为单栏。保留图库、查看器、编辑器的媒体尺寸和虚拟化布局。
- 页面以一个主要纵向滚动区域为主。列表很长、编辑器工具或选择器有明确边界时，可保留必要的局部滚动；不全局隐藏滚动条。
- 默认面板不加装饰渐变或模糊。不要用全局 CSS 覆盖所有按钮的尺寸、所有图片的圆角或所有列表的溢出行为。

## 控件、图表与交互

分段切换使用紧凑底框与中性选中底色，普通动作使用描边按钮。主动作允许灰蓝填充，文字使用 `--ui-on-accent`。悬停轻微提亮；键盘焦点要有可见描边，不能只靠悬停区分状态。

图表使用低饱和灰蓝／灰色序列和线型区分设备。时间走势采用保形平滑曲线，不制造数据点之间的极值。坐标线要弱于数据；图例可换行。悬浮只显示命中的曲线及其时间、数量，提示框保持小尺寸，并保留键盘读取能力。排名按行排列名称、数量、占比，以细条显示相对使用量。

动效以短暂的颜色和边界变化为主。尊重 reduced-motion；避免常规按钮悬停跳动、持续发光和与任务无关的动画。

## 地图与照片标记

底图参考 Dark 2D：石墨灰陆地、更深水面、低对比边界与道路、清晰分级地名。地理细节按缩放与视口逐步出现，不用大片纯色轮廓替代全部地图层次。使用同源地理数据实现该方向，准确说明数据精度。

照片参考 Apple 照片地图：真实缩略图、细浅色边框、数量角标和轻微叠层。地名独立放在照片下方，不铺成长条信息卡。标记随照片实际聚集位置自然分布，网格聚合只属于底层身份，不强制排列展示位置。靠得太近时合并，点击放大后展开；数量不能因视觉合并遗漏或重复。代表位置仍是附近区域提示，保留多地合并说明，不包装成精确 GPS。

## 实现与维护

`design-tokens.css` 在全局样式前引入，变量定义在 `:root`，确保挂载在 body 的菜单与对话框同样可用。既有 `--eagle-*` 是共用组件兼容别名，统一引用 `--ui-*`；不得在工作区重新定义另一套主题或让通用组件依赖照片统计的样式模块。

CSS Modules 继续拥有组件布局与状态选择器，颜色、控件圆角和共用尺度引用设计变量。组件专有颜色仅用于有业务含义的状态或内容。无需为了换肤复制素材／照片组件，也不创建并行组件库。

本次范围为网页登录、素材／照片工作区、共用导航与筛选、标签／智能文件夹、设置／处理／向量页面、摄影统计／地图／人物／智能整理、查看器与编辑器控件，以及共用菜单／弹窗。桌面端加载同一网页时继承主题；安卓 Compose、浏览器扩展和独立桌面连接配置页不属于本次网页改版。

## 验收

1. 在素材和照片之间切换，主题、焦点、选中状态一致，业务查询和选择状态不因换肤改变。
2. 检查图库、统计、地图、人物、智能整理、标签、设置、处理页面和至少一个弹窗／查看器。
3. 桌面与窄屏没有新增横向溢出，工具不会遮挡主要内容；小屏触摸目标保留。
4. 检查长名称、空状态、错误状态、键盘焦点和图表悬浮；不能仅凭构建成功宣告视觉完成。
5. 运行安全目标检查、架构门禁、lint、typecheck、unit test 和 build；不为纯视觉变量写镜像实现式测试。
