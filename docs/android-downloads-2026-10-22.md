# 安卓原件下载

0.4.0／10 新增独立原生单张／多张原件下载，网页和服务器业务接口保持不变，只在本机隔离服务与模拟器验证。

## 入口与使用

- 打开大图，点击底部下载图标，下载当前这一张原件。
- 在图库长按进入选择模式，选一张或多张，点击底部“下载”。照片与素材共用实现，每批最多 100 项。
- 保存到手机 `Download/SekerEagle`。照片、视频、RAW 保持原文件字节及扩展名，不将预览图冒充原件，不把手机上的查看旋转写进原片。
- 下载面板显示当前文件、当前字节进度、成功数量、失败明细；支持取消及“重试未完成项”。已经成功的文件不会在重试时重复下载。
- 同名文件通过 MediaStore 创建独立条目，由系统分配可用文件名；不会打开已有条目覆盖写入。用户主动再次下载会创建另一个副本，不改变服务器资源或备份检查点。

## 实现边界

NativeDownloads 持有冻结的会话、模式及资源快照，串行执行队列并记录本次结果；NativeDownloadStore 管理 pending 文件的创建、发布和失败清理；NativeDownloadPolicy 提供大小／类型校验、安全文件名与固定 64 KiB 缓冲复制。UI 不直接读 HTTP 或写文件，两种模式没有复制下载组件。

NativeSession 提取共用响应处理，JSON、预览和原件沿用相同认证、同源、续期及失效检查。原件仅访问共用 `/api/{photos|eagle}/assets/:id/original`，不跳转到对象存储、不把 Cookie 交给系统下载器或第三方 URL。禁止重定向；refresh Cookie 只用于 auth 路径；下载过程中注销或换身份会停止任务。

下载前读取当前模式下的授权元数据，拒绝媒体版本与选择时不一致的资源；响应必须是完整 200、匹配 MIME 和预期大小。复制过程中有界计数，拒绝超长与截断；完成后再次检查媒体版本，最后发布 pending 文件。失败／取消会移除本次未完成条目，保留本次此前已完成文件。文件名剥离路径、控制／双向格式字符及非法文件名符号，并保留扩展名、限制名称长度。

下载目录由 Android MediaStore.Downloads 管理，不新增全盘写入权限。依据 [Android 官方共享存储说明](https://developer.android.com/training/data-storage/shared/media)，Android 10+ 可直接创建和管理本应用拥有的 Downloads 条目。未发布的 pending 文件不作为完成下载显示。

当前任务随原生进程执行，旋转屏幕保留 ViewModel 队列；不承诺后台长期运行、进程被系统终止后的自动续传或跨重启恢复。进程被直接杀死时不能执行 finally，残留 pending 条目由系统过期机制管理；不会伪报该项已经保存。原件若已变更，需刷新图库后重新选择，不能绕过版本校验强制发布旧选择。

## 验证范围

- JVM 红测试确认缺少实现后提交 6563785，实现后同一测试转绿提交 54b79cb；覆盖精确复制、截断／超长拒绝、取消、类型与大小边界、危险文件名及扩展名保留。
- 真实隔离 API + Compose：大图单张保存、多选两张保存，读取手机文件与服务器原件比较；回到图库／退出选择后底部模式切换可用；跨模式元数据访问 404，不能创建下载条目。
- 模拟器本地 HTTP + 真实 MediaStore：重定向、HTML、长度不符、截断、下载中媒体版本变化均不能留下 pending 文件；取消、注销中断均清理未完成条目。
- 批量部分失败后，只重试失败资源；两次同名原件写入两个独立条目，完成内容一致；MediaStore 测试条目在 finally 删除。
- 原件 401 只续期一次，媒体请求只携带 access Cookie，refresh 请求才携带 refresh Cookie；既有原生登录／退出／预览安全测试继续回归。

验证结果于本文件末尾补充。小米实机上的文件管理器显示、慢网和后台行为仍需验收；不能把模拟器结果称为实机通过。

最终验证：28 项完整模拟器测试、38 项 JVM 单测通过；单张／多张真实接口流程打包后独立再跑通过，已检查实际下载结果和工具栏截图。Android lint／编译／构建、根仓库 lint／typecheck／unit test／build、架构及反例测试、格式检查通过。Java core 门禁覆盖率为行 97.89%、分支 85.81%，不代表 Compose 全应用覆盖率。调试包已导出，模拟器运行 0.4.0；网页、API 业务、生产和群晖均未改动。

0.7.1 补充：进度提示要求保持前台，离开应用主动停止，当前进程内可重试未完成项；下载前后元数据核验同样支持断开 HTTP 取消。队列取消保留当前项及后续项，重试后验证文件数量与原件字节。见 [审查复核](android-review-2026-10-23.md)。
