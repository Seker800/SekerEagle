# ADR 0003: Desktop multi-origin connection resolution

Status: accepted

## Context

One SekerEagle library can be reachable through loopback, a private LAN address, and a public HTTPS origin. A desktop client should use the fastest reachable path without confusing an unavailable endpoint with an untrusted browser origin, switching to an unrelated deployment, or making the web application responsible for recovering its own transport.

## Decision

The Electron main process owns validated connection settings, health probes, selection, persistence, and navigation. The React application receives only status and an action that opens a packaged custom-scheme manager. The manager remains usable when every HTTP endpoint is offline.

Automatic selection is sticky while the current endpoint remains healthy. On failure, all configured candidates are probed concurrently and the deterministic priority is Local, LAN, Public. Manual selection probes only the chosen slot and does not silently fail over. A versioned bootstrap response distinguishes unavailable, untrusted, incompatible, and different-deployment endpoints.

The first successful endpoint binds settings to a cryptographically random deployment identity generated by the API installation. Renderer input cannot change that identity or the active slot. Clearing the binding is a separate, local-page-only action with explicit confirmation.

## Consequences

- Origin-specific cookies remain isolated, so changing origins may require login even when both endpoints represent the same library.
- Cache keys continue to include the source origin. This can duplicate derived files across origins, but prevents an endpoint that learns a deployment identifier from poisoning another origin's cache namespace.
- LAN HTTP is an explicit trust exception limited to literal private addresses. Public endpoints require HTTPS.
- IPC that mutates connection state is accepted only from the packaged connection page; ordinary web content may read status and request that page.
- The web entry document must be revalidated so a long-running desktop installation discovers newly deployed hashed bundles.
