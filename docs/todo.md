## 本轮可自主完成的本地加固（2026-10-20）

本轮只修改本机仓库并使用新建临时测试实例，不重启、迁移或写入现有开发／生产服务，不推送或部署。

- [x] 修复新密码 UTF-8 超过 72 字节时 bcrypt 静默截断；保留旧长密码登录入口，允许用户换成安全长度的新密码。
- [x] refresh 记录绑定创建时的 authVersion；改密与登录／刷新交错时旧凭据不能续期。新增 migration 仅供后续部署，本轮只在临时库验证；首次应用将撤销全部历史 refresh 会话，要求重新登录。
- [x] JWT 固定 HS256 验证，保留现有令牌用途与模式校验。
- [x] 媒体进程环境白名单；HEIF 缺少专用工具时拒绝无检查回退。
- [x] 媒体使用经检查的数据库 MIME；危险类型附件下载、nosniff，保留 MP4 播放。
- [x] API 元数据响应（含失败）默认 no-store，媒体显式覆盖缓存策略；API、gateway、web 基础安全头与 web CSP Report-Only。
