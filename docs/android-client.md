## 0.9.1 自定义图片缓存（2026-10-25）

右上角菜单直接进入「缓存设置」，默认上限 512 MB，可输入 0–16384 MB，提供 128 MB／512 MB／1 GB／2 GB 快捷值、当前占用、保存及确认清理；0 关闭持久缓存。容量在照片／素材间共用，超过上限按最近使用顺序淘汰，降低上限立即缩容；清理不删除手机原图、下载或上传任务。内存位图仍独立有界，当前正在显示的图片不会因清理而变灰，也不会由旧下载回填已经清理的缓存。

图库列表仍以服务器授权为准，此功能不宣称完整离线图库；Android 系统可以回收缓存，丢失或损坏时安全重新下载。缓存目录由系统移除后可以自动重建，容量和缓存内容各自跨进程保留。安装包为 `apps/android/release/SekerEagle-0.9.1-android-debug.apk`，沿用旧调试版签名，无需部署服务器。 验证：完整 API 36 arm64 设备套件 65／65 通过，最终设置页／长列表／缓存安全等 8 项定向回归通过，零失败／跳过；写入后强制结束应用进程，再启动读取同一加密缓存成功。JVM 60 项、Lint 零错误（10 个既有警告）、核心行／分支覆盖率 96.9%／84.8%，完整 CI 通过。并发八次只请求一次图片，4200 条元数据索引换出后仍复用磁盘缓存；清理中的下载不使图片变灰且不能回填旧缓存。

## 使用

1. 首次打开在「账户」填写 SekerEagle 的 HTTPS 网关地址，在图库使用原账号登录。在「更多」顶部账号卡片可再次进入连接设置。调试 APK 额外允许 localhost／127.0.0.1 的 HTTP，正式构建不允许明文 HTTP。
2. 点击「更多 → 备份」进入「手机备份」，启用备份。应用为当前主体创建仅有 `asset:write` 的独立令牌，使用 Android Keystore 加密保存在应用私有目录中；网页拿不到令牌。可在网页版账号令牌管理中撤销「Android 手机备份」。
3. 选择一个或多个手机相册目录，或使用系统选择器授权其他文件夹。目录项可以修改目标模式、子目录范围或移除。初始目标为照片；切换当前浏览模式不会改变备份目标。目录移除不删除已备份资源。
4. 按需启用「打开时自动备份」。手机的定时任务只需打开应用；应用确认登录身份后自动执行，无需再次点击备份。
5. 可限制仅 Wi-Fi、仅充电。15% 及以下且未充电时暂停。首次大量上传可启用「专注备份」，在备份页保持屏幕唤醒。

小米／HyperOS 建议允许自启动、后台联网，并将省电策略设为无限制。应用提供系统设置入口；各机型设置名称不同，模拟器结果不能代替小米实机后台验收。

## 释放手机空间

在「更多 → 释放空间」主动检查。暂停正在进行的备份后，只枚举当前服务／部署／账号所选目录，要求同一模式已确认的文件检查点、原文件完整哈希与稳定性匹配，并重新确认服务器当前可见副本。未备份、变化、服务器已删除／无法确认、时间戳未知或权限不足的文件保留。检查计划一分钟后过期，继续清理前再次复核身份、文件和服务器；每批最多 500 项，可重复检查。

界面先显示数量与可释放容量，用户明确确认后，MediaStore 文件交给 [Android 系统删除请求](<https://developer.android.com/reference/android/provider/MediaStore#createDeleteRequest(android.content.ContentResolver,%20java.util.Collection%3Candroid.net.Uri%3E)>)，取消不继续清理；系统返回后核对文件是否移除。系统选择器目录只在用户授权可写时，经应用明确确认后逐文件再次复核并使用 DocumentsContract 删除；只读授权的旧目录需重新选择授予写权限才参与清理。清理不调用服务器删除 API、不清除成功回执，备份完成也不会自动清理。

## 数据语义与边界

- 支持的图片、RAW、视频格式与大小预算由 `library-core` 生成到 APK，服务端仍执行最终内容检查。不会上传文档、压缩包等任意文件，不压缩或修改原字节。
- 媒体目录只枚举未处于写入状态、未进系统回收站的项目；额外授权目录递归读取，逐文件检查大小、修改时间、哈希及读取稳定性。未知时间戳不会直接走快速跳过。
- 本地指纹是文件 URI、大小和修改时间。成功文件快速跳过；改名或移动后的相同内容通过内容回执跳过。文件变化会生成新的备份项，不覆盖旧资源。
- 内容回执、文件检查点、目录设置和上传会话按网关 origin、部署身份、账号及模式隔离。每个任务冻结目录目标模式，换服务、换账号或注销会停止当前任务。
- 新内容先通过共用 `/api/{eagle|photos}/uploads/check-content` 查询当前主体可见的未删除资源，只返回 `exists`，不返回资源 ID；已有内容不传输文件。并发上传仍由共用完成事务做最终去重。
- 服务器确认原文件入库后才记录成功；缩略图、人物等派生处理可以继续在服务端执行。SQLite 原子保存成功状态和内容回执；上传检查点保存会话 ID、哈希和分片大小，恢复时读取服务端已收分片，重新签名未完成分片。过期／已中止会话重新创建，入库中的会话保留待下次确认。
- 手机删除不删除服务器副本。服务器删除也不会使普通扫描反复补传；「重新检查全部文件」会清空本账号本机回执并重新检查，明确提示可能补传服务器已删除文件。
- 网络／电量不满足或任务中断时保留检查点，下一次打开或手动重试接续。当前版本不承诺在应用未打开时按固定时刻唤醒，也不承诺绕过 Android／HyperOS 的后台限制。
- Android 14 的部分照片授权不当作完整目录授权；相册目录备份要求完整图片和视频权限，避免静默漏传。系统授权仍受安卓目录限制；未被媒体库收录的 RAW 可以通过可授权的目录读取，不能访问其他应用私有目录。
- 应用禁用云备份和设备迁移，避免令牌与媒体 URI 授权在别的设备被错误复用。WebView 只在应用内导航到当前服务，禁用本地文件访问、混合内容及第三方 Cookie；上传链接要求签名和当前网关／loopback 来源。
