# 术语表（Glossary）

> 状态：现行 | 核验日期：2026-11-16 | 对应提交：319c087a
>
> 先在这里对齐词，再去读代码。每个词都写清“含义 → 代码入口 → 表/进程 → 不要和什么混淆”。

| 词               | 含义                                                     | 代码入口                                                   | 表 / 进程                                         | 不要和什么混淆                                                                                             |
| ---------------- | -------------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Eagle            | 历史前缀，当前大多表示“共享图库域”，不是 Eagle App       | `apps/api/src/eagle/`、`Eagle*` 模型                       | 共享能力                                          | 真正导入 Eagle 的代码在 `apps/eagle-migrator` 和 `apps/api/src/eagle/import`；其余 `Eagle*` 多是共享图库域 |
| Library / Asset  | 一个图库资源；`Library` 是共享域，`Asset` 是单条资源     | `EagleService`、`EagleAsset`                               | `EagleAsset`                                      | 不要把所有 `Eagle*` 都当成素材模式专用                                                                     |
| MATERIAL / PHOTO | 两个业务隔离的图库模式；底层实现共用                     | `library-capabilities.ts`、`photo-library.module.ts`       | `libraryMode` 列                                  | 不是两套独立系统，也不是前端过滤                                                                           |
| ownerId          | 资源所有者；只从认证主体推导，DTO 不接受                 | 各 controller 的 `principal.sub`                           | 所有业务表                                        | 不能由请求参数传入，也不能跨 owner 读取                                                                    |
| Operation        | 用户发起的一次批量操作，带租约、进度和终态               | `EagleAssetOperationService`                               | `EagleAssetOperation` / `EagleAssetOperationItem` | 不是 worker 的媒体任务                                                                                     |
| Command          | 操作的受理协议，负责幂等、参数摘要和事务入口             | `LibraryCommandRegistry`、`eagle-*-commands.ts`            | 原 operation/item 表                              | 不是新的队列或第二套状态                                                                                   |
| MediaJob         | worker 领取的持久媒体任务，共 11 种                      | `apps/worker/src/main.ts`、`media-job-contract.ts`         | `EagleAssetProcessingJob`                         | 不是用户批量操作                                                                                           |
| Task family      | 任务中心按类别聚合的策略／统计分类                       | `EagleTaskCenterService`                                   | `EagleTaskPolicy`                                 | 不是具体的 media job                                                                                       |
| Processing       | 媒体任务的设置与摘要页面                                 | `EagleProcessingService`                                   | 处理设置、心跳                                    | 不是用户操作进度                                                                                           |
| operations host  | 独立后台进程，执行用户操作、上传终结、恢复与维护         | `asset-operation-executor.ts`                              | 独立容器/进程                                     | 不是 API 进程里的定时器                                                                                    |
| business worker  | 领取媒体任务的业务执行器                                 | `apps/worker/src/main.ts`                                  | Compose `worker` 或 Mac launchd release           | 不是 operations host                                                                                       |
| library-reader   | 可重建的内存读取宿主，内部 HTTP 查询                     | `library-reader.ts`、`reader-*`                            | 独立容器，端口 3001                               | 不是业务事实源，也不是新的写入口                                                                           |
| memory / reader  | 同一件事的两种叫法；历史文件叫 memory，当前统一为 reader | `reader-store.ts` 等；旧文档仍可能写 `eagle-memory-*`      | reader 进程内存                                   | 不是浏览器内存缓存                                                                                         |
| projection       | 返回给界面的精简资源字段                                 | `eagle-asset-projection.ts`                                | 无独立表                                          | 不是完整实体，也不拥有写入                                                                                 |
| rendition        | 由原图派生的预览／编辑成片等文件                         | `EagleAssetRendition`、媒体服务                            | `EagleAssetRendition`                             | 不是原图；原图不可覆盖                                                                                     |
| pyramid          | 大图分层瓦片，用于查看器放大                             | `EagleImagePyramid`、worker 金字塔任务                     | `EagleImagePyramid`                               | 不是缩略图；缺失时可回退预览                                                                               |
| lease            | 后台任务的处理租约，防止两个进程同时处理同一项           | `eagle-asset-operations.service.ts`、worker `job-claim.ts` | operation/item、processing job                    | 不是用户会话或认证 token                                                                                   |
| revision         | 资源或媒体版本，写回与缓存据此拒绝旧结果                 | `rowVersion`、`mediaRevision`                              | 资源列／媒体版本                                  | 不是 Git revision                                                                                          |
| outbox           | 对象删除等外部副作用的可靠投递记录                       | `EagleObjectDeletion`                                      | `EagleObjectDeletion`                             | 不是业务删除本身；不能绕过 outbox 直接删对象                                                               |
| private          | 私密资源／私密视图，读取需额外授权                       | `EaglePrivacyService`、`privacy-visibility`                | `isPrivate`、隐私偏好                             | 不是“未登录”；也不等于删除或回收站                                                                         |
