# 安卓搜索与筛选合并

本次用户修正：查找条件集中到放大镜搜索页；右上角“视图”只管理显示方式。网页保持现状，仅改安卓原生客户端，沿用现有服务端查询契约。

## 使用流程

1. 点击放大镜，输入关键词，或选择标签、相机、镜头、导入日期、格式；“更多条件”可组合全部条件及最低评分、GPS。
2. 点击“查看结果”。输入框尚未提交的关键词与面板中的条件一起提交，避免选择条件后丢掉输入。
3. 结果顶部明确显示“关键词：…”、“标签：…”、“格式：…”等胶囊。点击胶囊或其 × 单独移除该条件，其余条件保留并重新查询。
4. “修改条件”重新打开搜索，保留当前关键词和条件；“清空”回到全部图库。结果页系统返回一次清空当前查询，返回图库；搜索编辑页关闭／返回保留原来的已提交查询。

## 查询语义

- 不同类别同时满足；标签多选匹配任意一个，对应既有 `manualTagIds` 与 `tagMatch=ANY`；格式多选匹配任意一种，对应既有 `formats`。
- 相机和镜头当前各为单选，面板明确标记“单选”；不会假称支持多相机并集。
- 时间仍是导入日期，使用本地自然日转 UTC 的既有参数，不改变照片首页拍摄时间排列。
- 分类面板中的“不限”只清除该类，不清掉其他隐藏条件；综合面板的“清空条件”清除全部条件。
- 关键词、条件、分页和移除操作统一走同一 GalleryState、NativeFilters、仓储和服务端查询；不新增手机侧全库筛选引擎，也不对已加载的几张图片做本地过滤。
- 模式切换与注销清理查询上下文；不会把照片的摄影条件带到素材模式。原生备份、批量管理与回收站继续使用既有流程。
