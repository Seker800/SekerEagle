# 安卓原生筛选与多选验收

## 本轮范围

0.3.0 在独立 Compose 流程补齐右上角视图筛选及长按多选；网页、API 业务规则和生产配置不变。仍仅使用本机临时数据库、对象存储和合成媒体。照片／素材复用同一套状态、筛选面板、仓储与选择操作，摄影选项按模式开放。

- 视图菜单提供标签、相机、镜头、时间、格式、综合筛选及 3／4 列布局。相机／镜头来自当前账号照片全库的摄影 facets；人工标签来自当前模式目录；格式来自服务端能力目录，不从当前已加载缩略图猜测。
- 标签按“同时包含”查询；综合筛选可组合最低评分、GPS、格式、标签与日期。所有条件交由服务器查询，分页携带同一条件。条件不持久化，切换模式清空；服务器仍决定 owner、模式与私密可见性。
- 日期筛选明确标为**导入时间**：对应现有 `createdFrom/createdTo` → `libraryAddedAt`。起止日期包含所选当地自然日，并按手机时区转成 UTC；不会把导入日期假称为拍摄日期。照片首页排列仍沿用服务器 chronologicalAt（拍摄缺失时回退导入时间）。拍摄时间范围查询及排序切换尚未接入。
- 长按提供系统触感反馈并进入选择模式，单击勾选／取消，点击日期标题选择该日期的已加载内容。全选明确为“全选已加载”，每次最多 100 项，不冒充全库全选。
- 支持批量添加／移除已有人工标签、评分 1–5／清除评分、移入服务器回收站；右上角三个点内“最近删除”可原生查看、选取及恢复。删除先确认，手机文件保持不动；释放手机空间仍由专门的备份清理流程处理。
- 写入冻结当前模式与选中资源，保存期间阻止重复提交和返回打断；成功刷新当前查询，失败保留选择并提供刷新退出入口。评分带 rowVersion，409 不自动覆盖；身份／模式变化不接受旧响应。
- 系统返回依次关闭面板、退出选择、返回大图／搜索／更多、退出回收站、清除筛选或搜索，最后才退出根页面。弹出的本地菜单／确认框优先处理返回。

## 验证记录

筛选参数和选择策略先编译红测试（缺少实现），提交 45272f7；实现后同一单测转绿，提交 1bd2a3e。日期测试固定 UTC；实际运行默认手机时区。

首轮完整模拟器回归 24 项通过（原有 23 项加新增真实接口流程）。最终回归、构建与检查结果见本文件末尾补充。小米实机尚未验收，不能据模拟器结果声称全面达到小米相册体验。

最终检查：24 项模拟器测试、33 项 JVM 单测通过；新增真实接口流程另外独立运行 2 次通过，覆盖批量标签、评分、删除／恢复、返回、模式选项差异、跨模式拒绝写入及 rowVersion 冲突。根仓库 lint、typecheck、unit test、build、architecture:check／架构反例测试、format:check 通过。原有 Java core 覆盖率门禁通过（行 97.54%、分支 86.74%）；此数字只代表 Java core，不代表新增 Compose UI 的覆盖率。

截图已人工查看，进一步统一筛选选项为灰白胶囊，避免 Material 默认紫色选中态混入现有黑色磨砂风格。版本号 0.3.0／7，调试安装包位于安卓 release 目录；最终仍需在用户小米手机上验证触感、系统返回、字号和长列表性能。
