# 照片编辑（第一阶段）

当前目标是在本机逐项开发和验证网页照片编辑，同时为后续手机 WebView 保留通用 UI 和处理逻辑；本阶段不添加手机壳、不进行 App 打包。

## 本地启动

使用 Node.js 22 和 npm 10，安装依赖后运行 `npm run dev --workspace @sekereagle/web`。
打开 `http://127.0.0.1:4173/dev/photo-editor`，选择本机 JPG、PNG 或 WebP 照片。
这个入口仅存在于 Vite 开发环境，不连接数据库、对象存储或鉴权接口，也不绕过正式页面的登录。
正式素材库在图片预览中提供「编辑照片」，读取认证接口提供的原文件，不以预览图冒充原图。
开发入口提供 6000 × 2696 的真实相机照片，并在浏览器 IndexedDB 中提供明确标识的「本地测试相册」；它不连接、也不冒充服务器素材库。示例来源和许可见 fixtures/ATTRIBUTION.md。

## 算法来源

预览和保存共用标准公式与 Apache-2.0 的 `@silvia-odwyer/photon` 0.3.3；WASM 随构建本地提供，无 CDN 请求。照片基本调整不再把滑块数值直接传入 Photon 的加法亮度或 HSL 增饱和接口。

- 曝光：-1…+1 EV，普通步长 0.01，共 201 个可选值。先用 W3C sRGB 传递函数转为线性光，再乘 `2^EV`，最后编码回 sRGB。不是旧的逐通道加减亮度。为已成片的相册照片采用此范围；它是本项目的交互取舍，不是 Adobe 的参数范围。相比先前 ±5 EV，同滑轨长度下拖动灵敏度降到五分之一；只减小 step 而不收窄范围，并不能解决鼠标和触摸拖动过敏。像素处理函数仍接受 ±5 EV，以保持底层 EV 语义。
- 对比度：-100…+100，步长 1，共 201 个可选值。使用 ImageMagick 公开的归一化 sigmoid（负值用反函数），中点 50%，保持纯黑、纯白及中性中点。本项目标定 `strength = 6 × abs(value)/100`，使 +50 对应其文档的典型强度 3；该标定不是 Adobe 的闭源实现。
- 饱和度：-100…+100，步长 1，共 201 个可选值。采用 W3C 的 sRGB 饱和度矩阵，系数 `s = 1 + value/100`，-100 为灰度、+100 为 2 倍色度。它与 Adobe 公开的端点语义相符，但不承诺与 Adobe 的内部色彩管理逐像素一致。
- 中间调：Photon `gamma_correction`，滑块 -100…100 映射到 gamma `2^(value/200)`，即约 0.707…1.414；比旧版 0.5…2 更温和。
- 复古、清冷：上游 `filter` 的 `vintage` / `oceanic`；黑白：`grayscale`。
- 滤镜强度：在调整后原像素与预设结果间做线性插值，保留 alpha。

新增 14 项均已接入真实像素处理，0 值跳过新增阶段，保留原有四项的中性输出和强度：

源码：[colour_spaces.rs](https://github.com/silvia-odwyer/photon/blob/master/crate/src/colour_spaces.rs)、[effects.rs](https://github.com/silvia-odwyer/photon/blob/master/crate/src/effects.rs)、[filters.rs](https://github.com/silvia-odwyer/photon/blob/master/crate/src/filters.rs)。
精确发布接口和行为以锁定的 npm 包内 `photon_rs.d.ts` 和 WASM 为准，主分支可能不同。

范围和语义参考 [Adobe Camera Raw 官方说明](https://helpx.adobe.com/camera-raw/using/make-color-tonal-adjustments-camera.html)和 [Adobe Lightroom API 参数范围](https://developer.adobe.com/firefly-services/docs/lightroom/guides/apply-edits/)。Adobe 没有公开其完整调色内核，不把这些实现称为 Camera Raw 算法。
公开数学依据：[W3C sRGB 转换](https://www.w3.org/TR/css-color-4/#color-conversion-code)、[W3C 饱和度矩阵](https://www.w3.org/TR/filter-effects-1/#feColorMatrixElement)、[ImageMagick sigmoid 公式](https://usage.imagemagick.org/color_mods/#sigmoidal)。
例如低饱和像素 `(132,120,108)` 在旧版 +10 后变成 `(142,120,97)`，新版 +10 为 `(133,120,107)`；测试固定这些参考值，防止轻微操作产生过强变化。

普通方向键或 +/- 按钮每次调整 1 个步长；Shift+方向键和 PageUp/PageDown 调整 10 个步长。数值框支持输入后回车，滑块双击归零。上述步长为本项目的交互选择，不能仅根据 Adobe 的显示范围推导内部步进。

预览最长边 1280，照片色彩处理放在 Web Worker 中；预览与全尺寸 PNG 保存使用相同处理函数、操作顺序和裁剪几何。参考 `LatestFrameWorker`，仅保留一个运行帧和一个最新待处理帧，丢弃过期的排队帧并结清对应 Promise；16 ms 合并交互事件，已完成的顺序帧可持续显示，只有当前参数完成后才允许保存。缓存只保留屏幕代理图，修改水印时复用已处理照片，不常驻完整分辨率的输入 / 输出缓存。
旋转按 90° 递增，支持水平镜像。裁剪工作区显示完整照片、半透明框外遮罩以及四角 / 四边共八个拖拽点；拖动框内移动裁切区域。默认自由模式，独立调整宽高；仅手动点选比例卡片后锁定比例。裁切区使用单行可滚动的比例卡片、横向／纵向切换及独立旋转／镜像操作，提供原始、1:1、4:3／3:4、3:2／2:3、5:4／4:5、16:9／9:16 和 21:9／9:21。自由模式切换横纵仅改变预设展示方向，不锁定当前裁切；固定比例切换方向则立即交换宽高。切回自由保留当前取景范围，重置回自由模式。固定模式拖动角点保持对角锚点，拖动边缘保持对边并以中心对称调整另一维；区域始终限制在照片内，触摸命中区 32 像素。一整次拖动合并为一次撤销，框及手柄都可用方向键微调；重置裁剪不清空调整和水印。不使用滚轮缩放，也不显示缩放滑杆。共享矩形几何决定预览和原始像素保存范围；裁切会减少输出尺寸，不人为插值放大。普通照片复用处理代理，颗粒 / 暗角开启时重新计算以保持效果相对裁切区域的位置。覆盖约束参考 sekerwatermark 的 CropMatrixCoverage，本实现使用原生网页指针事件及矩形取样，不调用 APK。
裁剪工作区先点击「完成裁剪」进入「成片预览」，再「保存到相册」；原图对比期间禁用保存。只有当前参数的预览处理完成后才能保存。
所有尺寸均使用参考 sekerwatermark `EditorScreen` 的纵向工作区：顶部关闭 / 撤销 / 重做 / 保存，中央照片，下方依次为对比与精细滑杆、分类、横向调整项，主工具导航固定在最底部。基础分类沿用「影调 / 色彩 / 细节」，选中调整项使用暖黄色实心样式。18 项均可使用，包括参考仓库的 17 项及现有「中间调」。分类记住选中项并自动滚动到可见位置；调整卡片双击归零，拖动一次产生一个撤销步骤，重复选择和未改变的设置不产生空历史。调整页重置只清空调整参数，保留滤镜、裁剪和水印。滤镜使用 60 像素小方块单行排列，支持触摸横滑、鼠标拖动、滚轮与左右翻页；切换滤镜保留强度。鼠标 / 触摸按住「对比原图」仅暂时关闭滤镜及全部调整效果，保留当前裁剪、旋转、镜像和水印及其显示尺寸；裁剪工作区保留取景框但对比时禁用拖动。松开恢复效果，键盘仍可切换对比；对比不修改编辑参数或撤销历史。

## 精细调色

在原有 18 项基础调整上新增去雾、明度降噪、色彩降噪，并在同一调整页提供 HSL、曲线、色彩分级三个工具。新增参数是共享 `PhotoEdits` 的纯数字字段，沿用同一个 Worker、撤销记录、精度控件、重置及保存链路；不建立另一套编辑器。「对比原图」同时暂时关闭所有新增效果，保留构图和水印。

- **HSL 八色混合器**：红、橙、黄、绿、青、蓝、紫、洋红，分别调整色相、饱和度、明度。使用 [CSS Color 4 的 sRGB / HSL 转换](https://www.w3.org/TR/css-color-4/#rgb-to-hsl)，按原始色相在相邻色区之间做 smoothstep 混合，红色色环首尾连续。色相 ±100 对应偏移 ±30°；饱和度按 `1 + value/100` 缩放；明度向黑／白端点混合。中性灰没有有效色相，不参与分色操作。
- **主曲线和 RGB 曲线**：每通道五个固定输入节点（0、25%、50%、75%、100%），可以直接拖动节点或使用滑杆／数值框、键盘调整输出位置。节点之间采用有界分段线性插值生成 256 项 LUT，没有样条过冲；主曲线后再应用各 RGB 通道，默认逐像素恒等。一次拖动合并为一次撤销，多指不会提前结束当前手势。
- **色彩分级**：阴影、中间调、高光分别设置色相、饱和度、明度，另提供明暗区域平衡。分区由平滑亮度权重混合；着色分量去掉 Rec.709 亮度后叠加，降低把颜色同时变成曝光偏移的耦合。只选色相而饱和度为零时不着色。这是本项目的分级标定，不宣称复制 Adobe 的内部算法。
- **去雾 / 加雾**：参考 [He、Sun、Tang 的暗通道先验](https://people.csail.mit.edu/kaiming/cvpr09/)，在最长边 256 的有界代理图估计局部暗通道和大气光，对透射率平滑后双线性映射到照片。正向恢复场景对比，负向混合大气光；平坦画面保守跳过。没有论文中的 soft matting，不承诺在天空、白色物体和强烈逆光下无光晕，也不能恢复丢失的 RAW 信息。
- **明度 / 色彩降噪**：3×3 双边邻域结合亮度差、颜色差及空间距离，分别混合亮度和色度；可见邻居以 alpha 加权，不引入透明像素的隐藏颜色。明度降噪保留部分原始细节；两项均为传统局部降噪，不是 AI 降噪，不承诺消除严重噪声。

合成顺序为：降噪 → 去雾 → 基础影调／色彩 → HSL → 主曲线／RGB 曲线 → 色彩分级 → gamma 与预设滤镜 → 锐化／清晰度／颗粒／暗角 → 裁切与水印。预览和全尺寸保存共用这些函数，全部中性时保留之前的像素输出。全尺寸降噪和调色的处理量随像素数增加，仍受既有 4800 万像素输入限制及浏览器内存边界约束；本轮不增加 RAW 解码、局部蒙版、透视矫正或生成式修复。

## 水印

调整选项、水印设置、分类和模板行均提供原生横向滚动、可见滚动条及按边界启用的左右翻页按钮；鼠标可拖动或使用滚轮横移，触屏可左右滑动，工具行聚焦后可用左右方向键翻页。短窗口的工具面板允许纵向滚动，末尾选项不再被固定高度裁掉。

- 参考用户 `seker水印` 项目的实际截图与模板配置，将原先 13 款同质化排版合并为 8 种**平面信息结构**，按「适合横图 / 适合竖图 / 横竖通用」定位。全部模板和「无水印」仍在同一连续列表中，上方标签只负责快速滚动，不筛掉其他排版。手动滚动同步标签高亮；选择、撤销和重做自动定位当前模板。
- 所有文字统一采用普通 400 字重的系统无衬线字体，无阴影、浮雕、描边、发光、纸张纹理、邮票、齿孔或网格装饰。纯色色块保持实色；所有文字固定为不透明纯黑或纯白；不提供透明度调节，不与照片混色。相同构图的左右位置与白字／黑字合并为设置，不再作为多款模板。旧模板 ID 映射到合并后的模板，保持当前编辑及撤销记录可解析。

参考项目仅只读研究；本仓库 Canvas 实现预览与导出，不连接或改动原 Android 项目，不引入 APK、品牌标识或提取字体，也不声称逐像素复刻原厂模板。所有文字仍来自本次编辑或真实摄影元数据。

- 根据模板能力提供白底 / 黑底 / 毛玻璃底或白字 / 黑字、拍摄参数和拍摄时间开关；「无水印」直接移除效果。
- 文字编辑面板只提供显示机型、拍摄参数、拍摄时间、网站地址四项，具有实时小预览。确认合并为一次撤销，取消或 Escape 不改动照片。
- exifr 只解析 Make / Model / FocalLength / FocalLengthIn35mmFormat / FNumber / ExposureTime / ISO / DateTimeOriginal。缺失字段保持空白，允许用户手动输入；已识别字段预填编辑框，可修改或清空。不填充“摄影作品”等占位标题。识别到拍摄时间时默认显示，用户可关闭。手动覆盖使用 null 表示沿用识别值，空字符串表示明确清空，不重新回填。显示文字与原 EXIF 分离，GPS 不解析。
- 统一合成顺序：照片调整与滤镜 → 几何裁剪 → 水印。照片调整只作用于照片，不影响水印底色、文字或边框。边框扩展画布，照片保留原有像素尺寸。预览、缩略图和全分辨率导出共用 `renderPhotoWatermark`。
- 输出安全上限 4800 万像素、单边 16384。输出仍为新 PNG，不自动把源 EXIF / ICC 写入 PNG；水印是可见文字，不能把它当作新增的真实拍摄元数据。

## 当前边界和后续验证

- 原图保持不变；「保存到相册」创建新的 PNG 素材，文件名带「已编辑」后缀和时间戳。重新打开保存后的照片从中性参数开始，不恢复之前的调整参数。
- 正式库通过现有认证分片上传流程保存。上传 DTO 只新增经过枚举校验的 `duplicatePolicy`；照片编辑指定 `CREATE_COPY`，普通导入保持 `SKIP`。用户资源归属继续由认证主体推导，不接受 ownerId 或 replacementAssetId。
- 编辑保存同时声明来源资源 ID 与行版本；服务端在会话创建和发布时校验当前 owner、模式与版本，发布时沿用源人工标签、私密状态、评分与说明，避免私密照片的编辑副本意外公开。来源被回收、清除或修改后拒绝发布，要求重新打开编辑器；原片不变。来源声明属于上传快照，不是资源的第二归属。
- 原图和保存回调在打开编辑器时冻结；方向键微调不会触发背后的图库切图。保存失败保留同一输出文件和上传会话，完成请求可幂等重放，结果读取失败只重试读取；更改编辑内容后才生成新的副本。普通导入仍保留原有失败取消逻辑。
- 输入上限 4800 万像素；浏览器解码仍可能占用较多内存，不能据此宣称已通过手机真机性能验证。
- 输出为浏览器 sRGB 画布编码的 PNG，不承诺保留原 EXIF、ICC、HDR 或 RAW 信息；透明 PNG 保留 alpha。
- 当前曝光是 SDR 照片的线性光调整，高光压缩只能调整已有 RGB 信息，不能恢复已丢失的 RAW 高光或 HDR 信息。自由角度拉直、透视校正和自动增强不在本轮新增调节与水印范围内。
- 当前曝光之后逐通道截断到 SDR 范围，没有高光滚降；对比度逐通道处理，饱和度使用图形滤镜矩阵。这些公式有公开依据，但组合效果未通过与成熟照片编辑器的参考输出比对，数学单测不等于照片观感验证。预览先缩小再调色，保存先全尺寸调色；非线性处理与缩放不交换，不能据共用函数声称二者逐像素一致。
- 不接入外部图片服务。正式环境的授权与存储边界保持原流程。
- 后续逐项完成编辑参数持久化、局部编辑、真机手势与内存验证。

## 连续调整与相机显影副本（2026-10-19）

影调、色彩、细节的 21 项基础工具连续横向排列，支持触摸、鼠标拖动、滚轮和翻页。分类用于定位对应组，浏览不会删除其他组，也不修改调整值；点击工具时激活对应组并使用原有滑杆、撤销和重置。HSL、曲线、色彩分级保留专属控件。

RAW 由共用 worker 生成当前版本最长边 6000 的 sRGB 无损 WebP，查看器以“编辑 RAW 显影副本”进入同一编辑器；保存继续创建 PNG 副本并验证来源 owner、模式和版本。浏览器不解码 RAW 原片，开发专用本地页面仍只接受浏览器原生 JPG／PNG／WebP；RAW 必须先经过正式库导入和服务器显影。

## 毛玻璃水印底板（2026-10-20）

摄影信息条、纵向参数栏、居中留白、上下分区和侧栏信息可选择毛玻璃底。使用当前照片居中铺满底板，按固定模糊度 60 处理后叠加 80% 黑色遮罩，文字为不透明纯白；只处理照片外围，主体像素与透明度保持原样。叠印模板保持白字／黑字选项，从毛玻璃底切换至叠印时采用白字。预览、缩略图、全尺寸 PNG 和撤销重做沿用同一主题状态与合成入口。

背景模糊复用现有可分离三角模糊，在最长边不超过 512 像素的代理画布上计算后铺回输出，模糊半径为最长边的 2.4%，保留局部轮廓与色彩变化，避免额外分配全尺寸卷积缓存，也避免浏览器 Canvas 滤镜支持差异。

毛玻璃底固定使用模糊度 60、黑度 80，不提供参数滑块或数字输入。删除对应编辑状态与额外面板高度，旧会话残留的滑块数值不再参与渲染。预览、缩略图与导出采用同一固定预设；主题切换及撤销重做保持原流程。

## 个人 LUT 导入

滤镜页的「导入 LUT」支持多选 `.cube` 和 PNG LUT，一批最多 128 个，单文件最多 16 MiB。CUBE 只接受 2–65 阶 3D 表，支持 DOMAIN_MIN / DOMAIN_MAX，拒绝 1D、未知指令、非有限值、行数不符和非法范围。PNG 支持 512×512（64 阶、8×8 分块）、64×64（16 阶、4×4 分块）和 N²×N 横条（N 为 16 / 32 / 64），按红轴优先、绿轴其次、蓝轴分片转换；解码前验证头部尺寸，只接受 8 位 RGB / RGBA PNG，并验证 CRC；直接读取 RGB 数值，忽略表图 alpha，不经过画布预乘或 ICC／gamma 变换。

通用代码不包含任何私人表、原项目目录或滤镜清单。用户选择的文件仅在浏览器中读取，表和名称保存在当前 origin 的独立 IndexedDB，不请求服务端、不进入数据库或对象存储，也不打包进发布产物。名称来自本地文件名，以普通文本显示；按源文件 SHA-256 去重。换浏览器／站点地址或清除站点数据需重新导入，原文件应自行保留。

选中 LUT 后使用同一滤镜强度、对比原图、撤销及导出流程。编辑历史仅保存不可变表 ID；渲染器按需加载选中的表，Worker 使用三线性插值，在影调／色彩／gamma 后、细节处理前应用并保留 alpha。表缺失或读取失败时明确报错，不偷偷回退其他滤镜。导入不会自动更换当前滤镜，坏文件不阻断同批其他文件，写入失败不显示成功。仅迁移 RGB LUT 调色，不自动包含来源软件附加的颗粒、暗角、柔光或专用安卓效果。

## 横图水印比例上限

字号、边距与边框共用布局返回的设计基准宽度：取照片宽度、照片高度的 1.5 倍、以及当前模板上下边框总量对应的高度预算中最小值。上下扩展区域合计不超过照片高度的 25%（约成片高度的 20%，允许像素取整误差）；不再通过侧栏模板的最小高度把全景图扩展成大块空白。竖图仍使用原照片宽度作为基准，保持原排版。

所有八种版式同步使用该基准计算字号和必要边距，超宽照片不因宽度继续增加而放大水印。照片像素和构图保持原样；预览、缩略图与导出统一使用同一尺寸规则，不新增字号或占比滑块。原生 Canvas 回归覆盖 6:1、12:1、24:1 横图、字段可见性、文字碰撞及竖图几何兼容。
