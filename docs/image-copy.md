# 大图复制

素材和照片共用同一个大图复制入口，普通查看器和照片组预览均使用 `EagleImageCopyButton`，经已有 `image-clipboard` 服务复制当前图片的完整优化预览。不得复制缩放后的屏幕截图、单张切片、图片地址或 RAW 原文件；RAW 同样复制可粘贴发送的预览图片。

网页端保留真正的 img 右键目标与浏览器原生菜单，不拦截 contextmenu。按钮在 localhost 或 HTTPS 且浏览器支持图片剪贴板 API 时写入 PNG；不支持或权限拒绝时保留窗口并显示失败原因，可重试。桌面端通过已有受信任 IPC 写入系统图片剪贴板。视频不显示图片复制按钮。

照片组切换成员后，复制源与反馈一并切换；旧请求完成不更新新照片的提示。复制期间禁用重复操作。共享组件不感知图库模式，不新增照片专用剪贴板链路。

验证：查看器、照片组预览、剪贴板服务及复制状态回归测试；Chrome 原生右键菜单可见“复制图片”；Chrome 按钮复制 DNG 派生预览后，macOS 预览可从剪贴板新建图片；隔离 Electron 实例的照片模式按钮通过原生桥复制 JPEG 后，macOS 预览可从剪贴板新建完整照片。测试实例仅连接本机一次性测试图库，未部署现用桌面程序。
